# لوحة التحقيق (Loahat Altahqeeq)

تطبيق تفاعلي لإنشاء لوحة تحقيق وربط الأدلة والملاحظات بالخيوط الحمراء، يعمل مباشرة في المتصفح أو كتطبيق سطح مكتب عبر Electron.

## المميزات الرئيسية

- **إضافة الصور:** عبر زر الرفع، أو السحب والإفلات، أو اللصق المباشر من الحافظة (`Ctrl + V`).
- **وصف الصور:** إضافة وتعديل وصف أسفل كل صورة، مع إمكانية تحرير النصوص بالنقر المزدوج.
- **الملاحظات والعناوين:** إضافة أوراق ملاحظات صفراء وبطاقات عناوين قابلة للتحرير والتحريك وتغيير الحجم والتدوير.
- **الربط بالخيوط الحمراء:** ربط البطاقات ببعضها بخيط أحمر تفاعلي أو فك الربط في أي وقت.
- **13 تصميماً للوحة:** فلين، سبورة سوداء، سبورة بيضاء، خشب، مخطط أزرق، داكن، ورق قديم، خشب جوز داكن، جدار إسمنت، جلد، قماش أخضر، جدار أبيض، خيش.
- **التحكم بالعرض:** تحريك اللوحة بالسحب، التكبير والتصغير بعجلة الفأرة أو الأزرار، وزر الملاءمة التلقائية.
- **الحفظ والنسخ الاحتياطي:** حفظ تلقائي محلي عبر `localStorage` مع دعم التصدير والاستيراد بصيغة `JSON`.

## طرق التشغيل

### 1) التشغيل المباشر في المتصفح
افتح ملف `index.html` مباشرة في أي متصفح حديث بدون الحاجة إلى تثبيت أي متطلبات.

### 2) التشغيل كتطبيق سطح مكتب (Electron)
تأكد من تثبيت [Node.js](https://nodejs.org/) ثم نفّذ الأوامر التالية داخل مجلد المشروع:

```bash
npm install
npm start
```

### 3) بناء نسخة Windows المحمولة (.exe)
```bash
npm run dist
```

## الملفات الأساسية في المستودع

- `index.html` — واجهة التطبيق ومنطق لوحة التحقيق بالكامل.
- `main.js` — نقطة دخول تطبيق Electron لسطح المكتب.
- `package.json` — بيانات المشروع وأوامر التشغيل والبناء.
- `package-lock.json` — قفل إصدارات الحزم المطلوبة لـ Electron.
- `.gitignore` — استبعاد `node_modules` وملفات البناء والمحرر.
- `README.md` — دليل المشروع وطرق التشغيل.
